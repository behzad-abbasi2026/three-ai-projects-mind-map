# Overview of Three AI Projects

**Designed by:** Behzad Abbasi Kharajou

This repository presents a visual mind map summarizing three AI projects.

## Projects

- **House Price Prediction:** Comparison of Linear Regression, Random Forest, and XGBoost models.
- **Disaster Impact Classification:** Comparison of Logistic Regression and an Artificial Neural Network (ANN).
- **Urban Object Detection:** Object detection using a pretrained YOLO model.
